A mobile-first HTML, CSS and JavaScript starter. No build step, no framework — just clean, modern, well-documented foundations to learn from or launch from.

Get started

What's inside

  • Mobile-first CSS

    Base styles target small screens; min-width media queries progressively enhance for larger viewports.

  • Responsive grid

    These cards use CSS Grid with auto-fit and minmax() — they reflow on their own, no breakpoints required.

  • Modern JavaScript

    The hamburger menu is an ES module with JSDoc and accessible aria-expanded state toggling.

  • Clean structure

    HTML, CSS and JS live in their own files. No single-file monolith — easy to read, easy to extend.

Getting started

No build step — just VS Code. Install the Live Server extension, then right-click index.html and choose Open with Live Server: 

Right-click index.html → Open with Live Server

Live Server serves the ES modules over HTTP and reloads on save — edit the files and watch it update. That's the loop.
