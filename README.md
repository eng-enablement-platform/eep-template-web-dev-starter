A simple, mobile-first HTML, CSS and JavaScript scaffold for learning and quick prototyping.

No build step, no framework, just simple modern foundations.

## Using this template

Two ways to start your own project from this template:

- **CLI (recommended)** - scaffold and re-purpose interactively. _Coming soon -
  the CLI is built from this template and will handle cloning, renaming, and
  stripping the parts you don't need._
- **Manual clone** - clone and make it your own by hand (below).

### Manual clone

```bash
git clone https://github.com/eng-enablement-platform/eep-template-web-dev-starter my-app
cd my-app
rm -rf .git && git init # start a fresh history that's yours
```

## Quick Start

All you need is VS Code and its dev server.

1. Open [VS Code](https://code.visualstudio.com/) and install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension
2. Clone this repo and open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.

### GitHub Pages

Every push to `main` deploys the site via [`.github/workflows/pages.yml`](.github/workflows/pages.yml).

One-time setup: in the repo go to **Settings → Pages** and set **Source** to **GitHub Actions**.
